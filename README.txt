WORK HOURS — FREE IPHONE WEB APP

What is included
- Weldflow and Security work groups
- Manual start/end entry — no clock-in/out
- No break field
- Hourly rate and automatic hours/pay calculation
- Weekly and monthly totals
- Calendar with worked-day markers
- History, edit and delete
- Local storage on the device
- JSON backup export/import
- PWA files for Home Screen installation

IMPORTANT FOR SAFARI HOME SCREEN
The app works as a normal HTML page, but Safari's proper Home Screen/PWA installation needs the files to be hosted at an HTTPS web address. The ZIP is ready for a free static host such as GitHub Pages.

Simple route
1. Unzip this folder.
2. Upload all files to a static HTTPS host.
3. Open the resulting HTTPS address in Safari on your iPhone.
4. Tap Share -> Add to Home Screen.

Your work records are stored locally in the browser/device. They are not sent to a bank or account by this app. Use Export Backup periodically if the records matter to you.
